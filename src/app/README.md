## Solar Potential Dashboard

This Streamlit dashboard visualizes solar potential across Benin, Sierra Leone, and Togo.

### Features
- **Country Selection**: Filter data by country.
- **Metric Selection**: Choose between GHI, DNI, and DHI for visualization.
- **Boxplot**: Compare solar metrics across countries.
- **Top Regions Table**: View countries ranked by average GHI.
